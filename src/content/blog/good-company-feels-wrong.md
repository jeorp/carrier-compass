いい会社にいるのに「なんか違う」。その感覚が気になるなら、**最近の仕事で手応えがあった場面と、負担だった場面を一つずつ残してみる**。会社全体を好きか嫌いか、すぐに結論を出さなくていい。

待遇や人間関係をありがたいと思っていても、仕事内容には違和感があるかもしれない。まずは理由を立派に説明することより、具体的な場面を拾ってみたい。

## 評価された場面と、自分がうれしかった場面を分ける

周囲からの評価と、自分の手応えが重なるかを振り返る。

褒められた仕事を続けたいとは限らないし、目立たない作業に満足することもある。どちらが正しいという話ではない。何に時間を使いたいのかを知るために、両方を見てみる。

以下は**架空の記入例**だ。

| 最近の場面 | そのとき感じたこと | 次に知りたいこと |
| --- | --- | --- |
| 急な依頼を短時間で処理した | 助かったと言われたが疲れた | 突発対応の分担を変えられるか |
| 顧客の課題を聞いた | もう少し時間を使いたかった | 提案業務を増やせるか |
| 会議の準備が続いた | 自分の役割が見えにくかった | どの成果につながる仕事なのか |
| 同僚と手順を改善した | 一緒に考える時間が楽しかった | 改善活動を担当する機会はあるか |

一日の気分だけで向き不向きを決めず、似た場面が繰り返されるかを見ていく。

## 記録は、気持ちの理由が分からないままでもいい

「なぜそう思ったか」まで書けない日は、出来事だけ残せる。

| 項目 | 記入例 |
| --- | --- |
| 今日、印象に残った仕事 |  |
| その場面で感じたこと |  |
| またやりたいこと・減らしたいこと |  |
| まだ分からないこと |  |

毎日続けることを義務にする必要はない。気になった場面を一つ書き、後で見返したときに共通点があるか考えるためのメモだ。

## 他人の働き方が気になったら、惹かれた部分を取り出す

友人の転職や昇進を、そのまま自分の目標にしなくていい。

自由な時間が増えた話に惹かれたのか、新しい仕事を学ぶ姿が気になったのか。同じ出来事でも、自分がほしいものは違う。職場や役職の名前から少し離れて、実現したい日常の場面に置き換えてみる。

選んだ仕事自体への後悔が大きいなら、[なんとなく就職した後悔の整理](/blog/vague-job-choice-regret/)を読める。

## 変えたいことが見えたら、相談できる形にする

メモの中から繰り返し出てきた希望を、一つの相談内容にする。

たとえば「突発対応を減らして提案の準備時間を取りたい」。その希望を社内でどう伝えるかは、[いい会社なのに辞めたい原因と相談の仕方](/blog/good-company-quit-consultation/)で扱っている。残るか転職するかまで比べるなら、[判断のメモ](/blog/mindset-career-change/)へ進める。

違和感を持っただけで、会社への感謝がなくなるわけではない。まずは、昨日より少し具体的な一文にしておきたい。
