仕事でメンタルが限界かもしれない。そう思っても、「まだ出社できているから」と相談をためらうことがある。

**限界かどうかを自分で証明してから、助けを求めなくてもいい。** 眠れないなどの不調が続く、生活や仕事に支障があるときは、医療機関や産業保健の窓口へ早めに相談してほしい。つらさが強ければ、一定の日数が過ぎるのを待つ必要もない。

この記事は診断のチェックリストではなく、困っていることを伝えるための案内です。出社できたことや、楽しい瞬間があることだけでは、健康状態を判断できません。

## いつもとの違いを、書ける範囲で残す

原因や病名を決める代わりに、「何が、いつから、どのくらい困るか」を短くメモする。

次は**記入例**です。症状の有無や件数で病気を判定する表ではありません。

| 伝える項目 | 記入例 |
| --- | --- |
| いつから | 先週から寝つきにくい夜が続いている |
| 生活への影響 | 食事を用意するのが難しく、食べる量も減っている |
| 仕事への影響 | 説明を聞いても内容が入りにくい |
| 相談したいこと | 体調について相談し、仕事の負担も見直したい |

仕事のせいだと確信できなくても、そのまま伝えて大丈夫。厚生労働省の[受診時の案内](https://www.mhlw.go.jp/kokoro/parent/consultation/hospital/hospital_04.html)でも、困っている症状を整理し、睡眠や食欲なども伝えることが案内されています。予約の要否は受診先へ確認してください。（2026年10月11日確認）

メモが作れないほどつらいときは、準備を終えることを相談の条件にしないでほしい。

## 体調の相談と、仕事の調整は別々に頼める

| 困っていること | 相談先の候補 |
| --- | --- |
| 不調の原因や治療について知りたい | かかりつけ医などの医療機関 |
| 体調を踏まえた働き方を相談したい | 職場で利用できる産業医・保健師など |
| 締切や担当を調整したい | 業務配分を決められる上司・人事 |
| どこに相談すればよいか分からない | 地域の保健所・精神保健福祉センターなどの公的窓口 |

受診するか迷う場合の地域窓口は、厚生労働省の[こころの相談窓口の案内](https://www.mhlw.go.jp/kokoro/youth/consultation/window/index.html)で確認できます。働く人向けには[こころの耳の相談窓口案内](https://kokoro.mhlw.go.jp/agency/)もあります。対象や受付時間は各窓口の最新情報を確認してください。（2026年10月11日確認）

仕事の相談窓口で話を聞いてもらうことと、医療機関で診断・治療を受けることは役割が違う。必要なら両方につながっていい。

## 最初の連絡は、困っていることを一つ伝える

以下は**文例**です。

> 眠れない日が続き、日中の仕事にも支障が出ています。体調について相談したいのですが、予約は取れますか。

職場には、診断を自分でつけて説明する必要はない。「体調の相談を予定しているので、今週の担当について相談したい」と、仕事上のお願いを分けて伝えられる。

社内の窓口では、詳しく話す前に、誰が対応し、どこまで共有されるかを確認したい。切り出す言葉は[仕事がしんどいと言えないときの文例](/blog/work-cant-show-weakness/)にもまとめています。

## 今すぐ結論を出すより、支えを増やす

休むか、働き方を変えるか、転職するか。全部を今日一人で決めなくてもいい。休養や勤務上の対応は、医療機関や職場の担当者と相談して考えたい。

不調を気の持ちようだけで片づけたり、商品や本を試すことを相談の前提にしたりしない。私は、うまく説明できない日にも「困っています」と言える入口を残しておきたいと思う。
