転職を決断するきっかけが欲しいときは、**今決めたいのが情報収集なのか、応募なのか、入社なのかを分ける**と考えやすい。仕事で嫌なことがあった日と、次の職場の条件に納得できた日は、別の日でもいい。

気持ちが動いた出来事は、考え始める理由になる。ただ、それだけで退職まで一気に決める必要はない。次の段階に進む材料があるかを確かめたい。

## きっかけと、決め手を分ける

何が起きて転職を考えたのかと、何を確認して判断するのかを別々に書く。

次は**架空の記入例**だ。

| 考え始めたきっかけ | 確かめたいこと | 今選べる行動 |
| --- | --- | --- |
| 希望した仕事を担当できなかった | 今後の担当変更は可能か | 上司へ見通しを聞く |
| 友人の仕事に興味を持った | 実際の業務と応募要件は何か | 公開求人を読む |
| 働く時間を変えたくなった | 現職で調整できるか | 勤務の運用を確認する |
| 希望に近い求人が見つかった | 条件と経験がどこで合うか | 応募書類を整理する |

「友人が動いたから自分も」という気持ちを否定せず、何に惹かれたのかを自分の希望へ言い換えてみる。比べたいのは友人の結果ではなく、自分に必要な条件だ。

## 応募前と入社前では、必要な情報が違う

応募は説明を聞く機会にもなるが、入社の判断には提示された条件を確かめたい。

情報収集の段階なら、関心のある職種や働き方が一つあれば始められる。応募するときは、募集要件と自分の経験、書類の準備を確認する。入社を検討するときは、業務や給与、勤務条件、開始時期などの説明を照合する。

一つの段階に進んでも、その後のすべてを決めたことにはならない。分からないことが出たら、質問する段階へ戻れる。

## 自分の判断理由を、あとから読める形にする

決め手は、勢いのある言葉より、確認した内容で残しておく。

| 項目 | 記入例 |
| --- | --- |
| 今回進めたい段階 |  |
| 実現したいこと |  |
| 説明や書面で確認できたこと |  |
| まだ分からないこと |  |
| 次に確認する相手・日 |  |

これは判断用のメモだ。実際に何を書くかは自分の状況に合わせていい。もし確認できたことが空欄ばかりなら、結論より先に情報を集める余地がある。

## 決め手が足りなければ、保留の理由を具体的にする

「勇気がない」で終わらせず、何が分かれば判断できるかを記す。
